快速开始

  • 进入对应目录，新建 .md 文件
  • 修改后执行 git add . && git commit -m "Update" && git push
  • 启用 Actions 后，PDF 备份会生成在 pdf/ 目录
⚠️ 使用建议：文件名用小写 + 短横线；日期型文件用 YYYY-MM-DD 前缀； 不要把密码 / 密钥 / 证件号明文入库。
